# Main-paper ablation

[`run.py`](run.py) reproduces the fixed-regularization 2 x 2 ablation on all 120
public scans. It crosses zero versus 50 RAP iterations with single-scatterer
versus phase-pair encoding while fixing axial/lateral regularization at
0.02/0.05, momentum at 1.0, and dynamic range at 51 dB.

From the repository root:

```bash
python experiments/main_ablation/run.py
```

The full run writes the following ignored outputs:

```text
outputs/experiments/main_ablation/
  zero_single/{detail.csv,summary.json}
  momentum50_single/{detail.csv,summary.json}
  zero_pair/{detail.csv,summary.json}
  momentum50_pair/{detail.csv,summary.json}
  ablation_results.json
```

Use a one-scan smoke test during setup:

```bash
python experiments/main_ablation/run.py \
  --limit 1 --bootstrap-replicates 1000
```

`--summarize-only` rebuilds `ablation_results.json` from completed configuration
directories without rerunning the scanner. Full runtime is hardware-dependent
and is expected to be tens of minutes.

[`ablation_results.json`](ablation_results.json) is the compact published
summary. Raw per-image evidence is generated by the command above rather than
stored in Git. Dataset version, archive hashes, and extraction instructions are
in [`../../docs/DATA.md`](../../docs/DATA.md).
